# Coordinate Portal — Minecraft Forge 1.7.10

Мод добавляет интерфейс телепортации по сочетанию **Tab + Q**.

## Возможности
- Координаты X/Y/Z (в текущем измерении).
- К игроку по нику (включая другое измерение, если оно загружено сервером).
- На мировой спавн (обычный мир / измерение 0).
- Сохранить одну личную точку там, где стоите; вернуться к ней позже. Сохраняется в NBT игрока.

**Важно:** это именно полноценная игровая механика; команды и читы не требуются. Сервер исполняет запросы и не доверяет клиенту. На сервере мод обязателен, каждому игроку нужен мод на клиенте. Доступ к телепорту имеют все игроки по умолчанию. Не рекомендуем использовать на публичном сервере без отдельного контроля разрешений.

## Установка и сборка
1. Установите **JDK 8**. Для Gradle ниже предпочтительна именно Java 8.
2. Установите **Gradle 5.6.4** (или используйте совместимый wrapper); этот исходный архив не содержит gradlew.jar и бинарных сборок.
3. Откройте терминал в папке проекта и выполните `gradle setupDecompWorkspace`, затем `gradle build`.
4. Готовый после успешной сборки JAR появится в `build/libs/CoordinatePortal-1.7.10-1.0.0.jar`.
5. Установите JAR в `mods` клиента и Forge-сервера **1.7.10 / Forge 10.13.4.1614**.
6. Откройте мир, нажмите **Tab + Q**. При открытой текстовой строке или другом интерфейсе сочетание не срабатывает.

Для GitHub: загрузите содержимое этой папки в репозиторий, добавьте workflow из `.github/workflows/build.yml`, откройте Actions → Build 1.7.10 Mod → Run workflow. Получите JAR в артефакте `CoordinatePortal-mod` (при успешной сборке).

## Особенности безопасности
- Для координат введены пределы: X/Z ±29 999 984; Y 1..254.
- Сетевые запросы обрабатываются на основном серверном потоке.
- Непосредственного поиска безопасного блока под ногами **пока нет**; по координатам можно оказаться в камне, лаве или воздухе. Перед телепортацией убедитесь, что место безопасно.
- Административные права не проверяются: телепортация доступна всем игрокам с модом.

## Состояние
